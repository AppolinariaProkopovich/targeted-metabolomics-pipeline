# Data availability and repository policy

This repository intentionally contains analysis code only.

The raw measurements, injection-order metadata, processed matrices, differential-analysis tables, pathway-analysis exports, and generated figures are not included because the underlying study data are not owned solely by the repository author and are not authorised for public redistribution.

The `.gitignore` file excludes common data and result formats as an additional safeguard. Users with authorised access should keep local files under `data/`, private settings in `config/config.R`, and generated outputs under `results/`.
